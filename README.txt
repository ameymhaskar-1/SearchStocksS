# NSE Stock Analysis Tool

A professional Streamlit web application to analyze NSE stocks, calculate momentum, and export beautiful Excel dashboards.

## Features
- **Smart Ticker Mapping**: Enter "Reliance" or "TCS", and the app finds the NSE ticker automatically.
- **Momentum Classification**: Automatically categorizes stocks into Strong Buying, Selling Pressure, Profit Booking, or Recovery.
- **Formatted Excel Export**: Generates a 3-sheet workbook with:
  1. Detailed analysis with conditional formatting.
  2. Pivot-style summaries.
  3. Visual Dashboard charts.
